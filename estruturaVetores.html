Estruturas Condicionais

Nesta página serão apresentadas as estruturas condicionais utilizadas em JavaScript. Elas permitem que o programa tome decisões de acordo com determinadas condições. Serão abordadas estruturas como if, else e switch, mostrando como utilizá-las para criar diferentes caminhos dentro de um programa.

Estrutura IF

A estrutura if permite executar um determinado bloco de código quando uma condição for verdadeira.

Estrutura IF / ELSE

A estrutura if / else permite escolher entre dois caminhos diferentes de execução.

Estrutura SWITCH

A estrutura switch permite verificar diferentes possibilidades para uma determinada expressão.
